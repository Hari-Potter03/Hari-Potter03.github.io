A full-stack web application that recommends cocktails based on a user’s taste preferences and ratings. A Python data pipeline collects and curates drink data (spirits, ingredients, tags, season), and a hybrid recommender (content + taste, optional ALS) is served via a FastAPI REST API. The React frontend provides onboarding, search/browse, and rating, delivering personalized picks in a smooth, local-first experience.
